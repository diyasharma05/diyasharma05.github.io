Projects

R.ai 4-level reasoning pyramid

Rationale.AI

A confidence-driven KPI intelligence-to-action engine. Detects material KPI movements with SQL, statistics and machine learning, climbs a four-level reasoning pyramid with a confidence gate at each step, and lets the language model write only the sentences. Finalist, Accenture Innovation Challenge 2026.

  • Python
  • DuckDB
  • scikit-learn
  • Streamlit
  • LLMs

Perception for Autonomous Vehicles

Three building blocks of a self-driving perception stack: YOLOv3 object detection in Keras, Deep SORT multi-object tracking on video, and a Multi-Task Attention Network for joint segmentation and depth on Cityscapes.

  • Keras
  • PyTorch
  • OpenCV
  • Cityscapes

Fabric Defect Detection

Two routes to finding defects on textiles: YOLOv8 instance segmentation, and a Segment Anything model whose mask decoder is fine-tuned with box prompts generated automatically from ground-truth masks.

  • PyTorch
  • Ultralytics
  • Hugging Face
  • OpenCV
L10 issues to knowledge graph

Layer 10 Memory: GitHub Issues Graph

A long-term memory system that turns raw GitHub issues into a knowledge graph: schema-enforced LLM extraction, entity and claim deduplication with provenance, a Neo4j and NetworkX graph, and hybrid FAISS retrieval with graph expansion.

  • Python
  • Neo4j
  • FAISS
  • Streamlit

Stock Price Prediction

A three-layer stacked LSTM on Apple daily closes with a 100-day window and a recursive 30-day forward forecast, with an honest look at where recursive forecasting breaks down.

  • TensorFlow
  • Keras
  • Time series

Multi-Task Attention Network

One SegNet-based network predicting a segmentation map and a depth map at once, with Dynamic Weight Average balancing the two losses. Trained for 100 epochs on Cityscapes.

  • PyTorch
