Hi, I'm Diya.

I'm a student at IIT Kharagpur. I build data infrastructure and machine learning systems, and I like being responsible for the whole path a byte takes: from the sensor that produces it, through the pipeline and the model, to the chart somebody finally reads.

This past summer I was a founding engineer at Intelligence Factory, a YC 2026 company, building the data backbone for a fleet of sensor-carrying robots. Before that I worked on quadruped locomotion at TU Munich, text-to-SQL at Ixigo, and defect detection with Caltech.

Away from all this I write poetry and play badminton, badly on some days and well on others.

Projects

All of these are on GitHub. Some are recent, some are from when I was starting out.

Rationale.AI

A KPI engine we built for the Accenture Innovation Challenge 2026, where it reached the final. It finds material movements with SQL, statistics and a bit of machine learning, climbs a four-level reasoning pyramid with a confidence gate at each step, and only then hands the finished numbers to a language model to write up. The rule I'm proudest of: the LLM never computes a number.

Perception for autonomous vehicles

Three notebooks: YOLOv3 built layer by layer in Keras and loaded with Darknet weights, Deep SORT tracking on top of it, and a Multi-Task Attention Network doing segmentation and depth at the same time on Cityscapes.

Fabric defect detection

The Caltech work, in public form. YOLOv8 segmentation on a textile dataset, and a Segment Anything model whose mask decoder I fine-tuned with box prompts generated from the masks.

Layer 10 memory

Turns a pile of GitHub issues into a knowledge graph: schema-enforced LLM extraction, deduplication that keeps provenance, Neo4j and NetworkX for the graph, FAISS for retrieval.

Stock price prediction

An early one. A stacked LSTM on Apple closing prices with a recursive 30-day forecast. The README is honest about where recursive forecasting falls apart.
